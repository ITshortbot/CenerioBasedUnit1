# Python OOP Management Systems (CenerioBasedUnit1)

This repository contains two Python-based console applications that demonstrate core Object-Oriented Programming (OOP) concepts. These assignments focus on class design, object instantiation, and building interactive command-line interfaces (CLI).

## 📁 Projects Included

### 1. Mobile Store Management System
A CLI application to maintain and manage mobile phone inventory.
* **File:** `mobile_store.py`
* **Features:**
  * **Add Mobiles:** Store new mobile phones with their Brand, Model, and Price.
  * **Auto-Categorization:** Automatically classifies phones into `Premium` (₹50,000+), `Mid-range` (₹15,000 - ₹49,999), and `Budget` (< ₹15,000) based on their price.
  * **Display Inventory:** View a formatted list of all available mobiles in the store.
* **Core Classes:** `Mobile`, `Store`

### 2. Vehicle Showroom Management System
A CLI application to manage a vehicle showroom's inventory.
* **File:** `vehicle_showroom.py`
* **Features:**
  * **Add Vehicles:** Store new vehicles with their Vehicle Number, Brand, and Price.
  * **Auto-Categorization:** Automatically classifies vehicles as `Luxury` (₹20,00,000+) or `Economy` (< ₹20,00,000) based on the given price.
  * **Display Inventory:** View a formatted list of all vehicles currently in the showroom.
* **Core Classes:** `Vehicle`, `Showroom`
